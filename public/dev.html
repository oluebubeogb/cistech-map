App Config

Place category labels

Friendly names for place types used in Nearest landmarks (and search). Leave blank to use an auto title-case of the raw type id.

Footer attribution

Text shown at the bottom of the map. HTML is allowed (links, · separators). Leave empty to use the default.

Site icon

URL of the logo shown in the left rail and as the browser favicon. Use a square PNG/SVG (recommended 64×64 or 128×128).

Feature flags

Live location sharing is not ready yet. Keep it off so the left-nav item stays hidden on the map.

When off, the “Location sharing” icon is removed from the map UI.

How-to Guides

1. Cloudflare Tunnel (map.collab.name.ng)

Point your domain to this service with zero open ports:

cloudflared tunnel login
cloudflared tunnel create mahp-map
cloudflared tunnel route dns mahp-map map.collab.name.ng
cloudflared tunnel run --url http://localhost:3847 mahp-map

Or one-liner for quick test:

cloudflared tunnel --url http://localhost:3847

Then set the CNAME / public hostname in the Cloudflare Zero Trust dashboard to map.collab.name.ng.

2. Using the Map API (like a normal map service)

Authenticate with header X-API-Key or query ?api_key=....

curl -H "X-API-Key: YOUR_KEY" \
  "https://map.collab.name.ng/api/search?q=umuahia"

curl -H "X-API-Key: YOUR_KEY" \
  "https://map.collab.name.ng/api/distance?lat1=5.52&lon1=7.48&lat2=5.53&lon2=7.50"

3. Embed a map for your users

Full UI or minimal:

<!-- Full featured -->
<iframe src="https://map.collab.name.ng/embed?api_key=YOUR_KEY" width="100%" height="500"></iframe>

<!-- Simple: only map + search + zoom -->
<iframe src="https://map.collab.name.ng/embed?api_key=YOUR_KEY&features=search,zoom" 
  width="100%" height="500"></iframe>

<!-- With routes + measure -->
<iframe src="https://map.collab.name.ng/embed?api_key=YOUR_KEY&features=search,zoom,routes,measure" 
  width="100%" height="500"></iframe>

Available features: search, zoom, routes, measure, menu, fullscreen

4. Changing the secret Dev path

Edit the value above (or edit config/app.json → devPath) then restart the server. Current path is shown in the browser address bar.

5. Custom map style for clients

Clients can fetch the live MapLibre style:

GET /api/maplibre-style

Or pull colors/icons:

GET /api/style
